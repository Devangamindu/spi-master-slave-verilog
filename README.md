# SPI Master-Slave Communication in Verilog

## Overview

Designed an SPI communication system in Verilog HDL consisting of Master and Slave modules.

## Features

- SPI Master
- SPI Slave
- Serial data transmission
- Serial data reception
- Clock generation
- Chip-select control
- Shift-register based communication

## SPI Signals

- SCLK
- MOSI
- MISO
- CS

## Architecture

SPI Master <----> SPI Slave

## Verification

Verified Master-Slave communication using Xilinx Vivado simulation and waveform analysis.

## Concepts

- Serial communication
- FSM design
- Shift registers
- Synchronous data transfer
- Protocol implementation
